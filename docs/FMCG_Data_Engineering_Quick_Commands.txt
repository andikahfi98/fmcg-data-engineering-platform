============================================================
1. START WSL
============================================================

From Windows PowerShell:

wsl -d Ubuntu-24.04


============================================================
2. ENTER PROJECT FOLDER
============================================================

cd "/mnt/d/BISMILLAH DATA/Project/Data Engineer/FMCG Batch & Streaming Data Engineering Platform"


============================================================
3. ACTIVATE PYTHON VIRTUAL ENVIRONMENT
============================================================

source .venv/bin/activate

Expected terminal prefix:

(.venv)


============================================================
4. LOAD .ENV VARIABLES
============================================================

set -a
source .env
set +a

Optional checks (do NOT print password):

echo "$POSTGRES_USER"
echo "$POSTGRES_DB"
echo "$POSTGRES_PORT"


============================================================
5. START DOCKER SERVICES
============================================================

Start all services:

docker compose up -d

Check status:

docker compose ps

Expected important services:

fmcg_postgres
fmcg_airflow


============================================================
6. ENTER POSTGRESQL
============================================================

docker compose exec postgres sh -lc \
'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB"'

Expected prompt:

fmcg_dw=#

Useful PostgreSQL commands:

\dn
\dt raw.*
\dv raw.*
\dt staging.*
\dt warehouse.*
\dt metadata.*

Exit PostgreSQL:

\q


============================================================
7. QUICK DATABASE CHECKS
============================================================

Inside PostgreSQL:

SELECT COUNT(*) FROM raw.current_sales;

SELECT COUNT(*) FROM staging.stg_sales;

SELECT COUNT(*) FROM warehouse.fact_sales;

Expected sales count:

130995


Check active source versions:

SELECT
    pipeline_name,
    source_name,
    active_run_id,
    LEFT(active_source_hash, 12) AS active_hash
FROM metadata.source_state
ORDER BY pipeline_name, source_name;


============================================================
8. AIRFLOW
============================================================

Airflow UI:

http://localhost:8080

Show Airflow local admin credential:

docker compose exec airflow \
cat /opt/airflow/simple_auth_manager_passwords.json.generated

Do not share or screenshot the password publicly.


Check Airflow DAGs:

docker compose exec airflow airflow dags list

Check FMCG DAG only:

docker compose exec airflow airflow dags list | grep fmcg_batch_pipeline

Check DAG import errors:

docker compose exec airflow airflow dags list-import-errors

Airflow logs:

docker compose logs -f airflow

Exit log view without stopping container:

Ctrl + C

============================================================
15. STOP PROJECT SAFELY
============================================================

Stop containers but KEEP database data:

docker compose down

Or just stop containers:

docker compose stop


============================================================
IMPORTANT - DO NOT USE
============================================================

DO NOT run:

docker compose down -v

unless you intentionally want to delete Docker volumes.

The -v option can remove the PostgreSQL volume and delete project database data.
